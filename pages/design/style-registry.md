## 6. Выстройка компонентов (05.10.2026)

По этому реестру собрана статичная галерея **`design/components/`** — каноничный источник для копирования компонентов в будущее:

- `css/components.css` — вся система: токены (§1) + все компоненты (§3) с ховер-состояниями.
- `01-tokens.html` … `07-header-footer.html` — по странице на группу (токены/типографика, кнопки, поля+дропдаун, чипы+severity+теги, стата-карточка+свитчер, дэшборд, шапка/футер).
- `compare.html` — «наш компонент ↔ кроп из фигмы» по каждой группе (кропы в `crops/`, нарезаны из `../figma-shots/`).
- Смотреть: `cd design/components && python3 -m http.server 8137` → `http://127.0.0.1:8137/` (нужен http: иконки-маски и Inter с Google Fonts).

Иконки чипов — маски (`mask: var(--m)`) над `background: currentColor`, поэтому перекрашиваются navy↔белый сами. **Грабля:** `url()` внутри custom property резолвится относительно css-файла, где var() **используется** (`css/icons/…` → 404) — в инлайнах писать абсолютный путь `/icons/…`.
